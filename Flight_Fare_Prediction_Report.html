1. Introduction

Data Analysis and Visualization is the systematic process of gathering, cleaning, transforming, and visualizing data to reveal meaningful patterns and facilitate automated decision-making. In the modern aviation sector, dynamic pricing strategies cause flight fares to change constantly based on flight lead time, available seats, route distance, airline brand tier, and cabin class.

This project applies the end-to-end DAV workflow to a comprehensive 10,000-record dataset of Indian domestic flights covering 6 major metro hubs (Delhi, Mumbai, Bengaluru, Hyderabad, Kolkata, Chennai). The project covers missing data imputation, duplicate checks, statistical data exploration, interactive Plotly visualization dashboards, comparative machine learning regression modeling, and deployment of a multi-page interactive Streamlit web application.

2. Objectives

  • Clean and prepare a multi-attribute flight dataset containing missing values and verify absence of duplicates.
  • Analyze pricing dynamics across airlines, departure times, travel classes, and route distances.
  • Quantify non-linear pricing effects, such as the exponential last-minute booking price surge and seat scarcity elasticity.
  • Build interactive visualizations (histograms, pie charts, scatter plots, correlation heatmaps) using Plotly.
  • Implement and evaluate two regression models (Linear Regression and Random Forest Regressor) using $R^2$, $RMSE$, and $MAE$.
  • Deliver the project via an interactive, cloud-deployed Streamlit web dashboard with a live fare prediction calculator.

5.2 Data Cleaning & Median Imputation (app.py)

@st.cache_data
def clean_data(raw: pd.DataFrame):
    df = raw.copy()
    report = []
    for col in ["duration_hours", "seat_availability_pct", "airline_rating"]:
        n_missing = int(df[col].isna().sum())
        median = float(df[col].median())
        df[col] = df[col].fillna(median)
        report.append({"Column": col, "Missing values": n_missing,
                       "Cleaning method": f"Filled with median ({median:.2f})"})
    n_dupes = int(df.duplicated().sum())
    df = df.drop_duplicates()
    return df, pd.DataFrame(report), n_dupes

8. Exploratory Data Analysis (EDA)

Exploratory Data Analysis was conducted using statistical aggregations and dynamic Plotly charts to understand key patterns:

  • Fare Distribution: The overall mean fare is ₹9,142 with a median of ₹7,250. Fares exhibit a right-skewed distribution caused by premium business class tickets and urgent last-minute bookings.
  • Travel Class Comparison: Business class tickets average ₹22,450, Premium Economy averages ₹11,920, and Economy averages ₹6,840. Cabin class is the single strongest price driver.
  • Last-Minute Price Surge: Tickets booked less than 10 days before departure experience an exponential price surge due to high demand and limited seat inventory.
  • Carrier Pricing Dynamics: Full-service carriers (Air India) show higher baseline fares, while low-cost carriers (SpiceJet, Akasa Air) maintain competitive economy fares.

10. Machine Learning Models and Comparison

Two distinct regression models were evaluated on an identical 80/20 train-test split (8,000 training records, 2,000 testing records) using standard evaluation metrics: Mean Absolute Error ($MAE$), Root Mean Squared Error ($RMSE$), and Coefficient of Determination ($R^2$).

Regression Model Mean Absolute Error (MAE) Root Mean Squared Error (RMSE) R² Score (Accuracy) Performance
Linear Regression ₹1,624.76 ₹2,366.82 0.844 (84.4%) Baseline Model
Random Forest Regressor (150 trees) ₹922.30 ₹1,424.86 0.943 (94.3%) BEST MODEL

Model Performance Analysis

Random Forest is clearly the superior model, achieving an $R^2$ of 0.943 and reducing prediction error ($MAE$) by 43.2% compared to Linear Regression.

Scientific Rationale: Flight ticket pricing in real-world aviation is inherently non-linear. Linear regression assumes a fixed additive increase per day and per seat. In contrast, Random Forest uses an ensemble of 150 decision trees that split on complex interactions (such as the exponential price surge for last-minute business class bookings with low seat availability).

14. Key Findings

  • Cabin Class Impact: Travel class is the single largest determinant of ticket fare, contributing over 54% of feature importance. Business class costs an average of 3.2× Economy class.
  • Booking Advance Window: Tickets booked less than 7 days before departure surge by up to 160% compared to tickets booked 30+ days in advance.
  • Seat Scarcity: Low seat availability (< 15%) triggers demand-based surge pricing across all airlines.
  • Ensemble Accuracy: Random Forest outperforms Linear Regression by 9.9% higher $R^2$ and 43.2% lower $MAE$ due to its ability to capture non-linear relationships.

15. Limitations

  • The dataset is synthetic with realistic non-linear modeling; real-world airline pricing incorporates additional external factors such as jet fuel price volatility and competitor price tracking.
  • Weather anomalies and flight delay probabilities are not currently modeled in the dataset.
